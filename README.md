## In this project I have used TypeScript, React and Tailwind to make an online shop providing products for sale.

## Features

- Being presented all the products in a neat setup
- Being able to see what products are on sale and how big the discount is
- Being able to put products directely in the cart from the mainpage
- Being able to inspect products further by looking at them with more details as well as reading the reviews
- Being able to see products tags, filter between them and search for certain products
- Going to cart and checking out
- Being able to fill out a contact form

---

## 📦 Getting started

Follow these steps to install locally:

1. Clone repository:
   `git clone https://github.com/Liz-nor/JSF.git`

2. Open the repository:
   `cd JSF`

3. Use `npm run dev` in terminal and follow the link.
